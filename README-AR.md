# NamNam kids — مشروع تطبيق أندرويد

التطبيق غلاف WebView يحمل صفحتك داخله ويحفظ الفيديوهات والصور في تخزين التطبيق نفسه (دائم، وبلا إنترنت).
لا يطلب أي صلاحيات، ولا يحتاج اتصالًا بالشبكة.

## الطريقة 1: بناء سحابي مجاني (بدون تثبيت أي برنامج) — من كمبيوتر
1. أنشئ حسابًا على github.com ثم مستودعًا جديدًا (New repository) باسم NamNamKids.
2. اضغط "uploading an existing file"، ثم اسحب **محتويات** هذا المجلد كلها (بما فيها المجلد المخفي `.github`) وأفلتها، ثم Commit.
3. افتح تبويب **Actions** ← "Build APK" ← انتظر 3-5 دقائق حتى تظهر علامة ✅.
4. افتح التشغيل الناجح ← في الأسفل **Artifacts** ← نزّل `NamNamKids-apk` (ملف zip فيه `app-debug.apk`).
5. انقل الـ APK للهاتف وثبّته (اسمح بـ"التثبيت من مصادر غير معروفة" للمتصفح أو مدير الملفات).

## الطريقة 2: Android Studio
1. ثبّت Android Studio ثم File ← Open ← اختر هذا المجلد، وانتظر مزامنة Gradle.
2. Build ← Build Bundle(s)/APK(s) ← Build APK(s).
3. الملف في: `app/build/outputs/apk/debug/app-debug.apk`.

## ملاحظات
- لتحديث الصفحة لاحقًا: استبدل `app/src/main/assets/index.html` ثم ابنِ من جديد. التحديث فوق النسخة المثبتة يحافظ على المكتبة (ثبّته بدون حذف القديم).
- النسخة المبنية هي debug موقّعة بمفتاح تجريبي: تعمل وتُثبّت عادي، لكنها لا تصلح للنشر على Google Play.
- التخزين السحابي (حساب claude.ai) غير موجود في هذه النسخة؛ الحفظ على الجهاز نفسه.
